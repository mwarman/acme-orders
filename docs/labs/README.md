# Labs

Take-aways for after the course are in [`docs/takeaways/`](../takeaways/README.md).

Start any lab on its own branch from a published starting point:

```bash
scripts/lab-start.sh list
scripts/lab-start.sh m5
```

Each handout has the same shape: **task**, **success looks like**, and an optional **stretch**. Work in trios when your instructor says so: one drives, one reviews the diff, one tracks where the prompt went wrong.

| Lab | Handout | Focus |
|---|---|---|
| M2 | [m2.md](m2.md) | First contact: understand an unfamiliar repo |
| M3 | [m3.md](m3.md) | Prompting and plan mode |
| M4 | [m4.md](m4.md) | Context engineering with CLAUDE.md |
| M5 | [m5.md](m5.md) | Verification loops and diff review |
| M6 | [m6.md](m6.md) | Everyday workflows (menu) |
| M7 | [m7.md](m7.md) | Commands and skills, MCP, subagents, choosing the mechanism (hooks are M7d) |
| M8 | [m8.md](m8.md) | Safety and governance: untrusted input, layers, policy mapping |
| M7d | [m7d.md](m7d.md) | Hooks (continue on your M8 branch) |
| M9 | [m9.md](m9.md) | Scaling out: parallel sessions, unattended runs, cost |
| M10 | [m10.md](m10.md) | Capstone |
