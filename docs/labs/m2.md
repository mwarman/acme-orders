# M2: First contact

**Start:** `scripts/lab-start.sh m2`

## Setup
Start Claude Code in **plan mode**. It can read and search but cannot edit, which keeps you honest:

```bash
claude --permission-mode plan
```

(or press Shift+Tab until the status bar shows plan mode).

## Task
Do **not** edit code. Use Claude Code to answer these six questions about the repo:

1. Walk through what happens when a customer places an order, from HTTP request to database.
2. Where is refund approval decided, and who can approve what?
3. What does `src/legacy/pricing` do, and who calls it?
4. How does the code talk to the database?
5. Which parts of the code have no tests?
6. Which parts of the code look unused?

## In your trio
- **Driver** types the prompts. **Reviewer** reads the code the agent cites. **Observer** notes how many files it read, where a prompt went wrong, and anything it stated that you doubt.
- Post your status in the shared channel: 🟢 done, 🟡 slow, 🔴 blocked.
- **Checkpoint:** questions 1 to 3 answered by the halfway mark.

## Success looks like
Your trio submits an answer to each question **plus one claim you verified yourself**: you opened the file, read the lines, and either confirmed or corrected what the agent said. Asking the agent again does not count.

## Stretch
Ask for a Mermaid diagram of the refund flow, then check one arrow against the code.
