# M4: Context engineering

**Start:** `scripts/lab-start.sh m4` (there is no `CLAUDE.md` yet)

## Why this lab
In M3 you counted how often your group repeated the same instruction. Facts about this repo that the agent had to be told again belong in a file that loads every session. Your job: **earn every line**.

## Controls (read these first)
- **Turn auto memory off** for this experiment. Claude may already have saved notes from earlier modules, which would make your "before" run look better than it is. Start Claude Code with `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1 claude`, or use the toggle in `/memory`.
- Use the **same prompt text** in both runs.
- Use a **fresh session** for each run (`/clear` or restart).
- Keep each run on **its own branch** (steps below), so your `CLAUDE.md` is never lost and run 2 starts from clean code.

## Task (12 minutes)
Pick one task. Use Manual mode so you see each edit and command.

- **A:** *"Add an optional `q` query parameter to `GET /catalog/products` that filters products by a case-insensitive part of the name, with tests."*
- **B:** *"Add unit tests for the helpers in `src/common/money.ts`."*

1. **Run 1, no `CLAUDE.md`.** First `git switch -c m4-run1`. The **observer** tallies every **correction** and every **command or convention you had to name**.
2. Save run 1: `git add -A && git commit -m "run 1"`, then `git switch work/m4` to get back to clean code.
3. **Write `CLAUDE.md`** on `work/m4`, from your tally and [`docs/claude-md-template.md`](../claude-md-template.md). Start Claude Code and run `/context`: confirm it shows under **Memory files**.
4. **Run 2:** `git switch -c m4-run2` (your uncommitted `CLAUDE.md` comes with you), start a **fresh session**, and run the **same prompt**. Tally again.
5. **Compare** the two branches and the two tallies.

## In your trio
- **Driver** prompts. **Reviewer** reads each edit and command. **Observer** keeps the tally.
- Status: 🟢 done, 🟡 slow, 🔴 blocked.
- **Checkpoint:** by about minute 5, run 1 is done and tallied.

## Success looks like
- A tally for each run, so the comparison is evidence, not a feeling.
- A `CLAUDE.md` where **every line is tied to something you observed**.
- Fewer corrections in run 2, **or** a clear explanation of why not. "No difference" is a valid, useful result: it means your file should be short.

## Check every line
- Did the agent get this wrong (or would a new teammate)?
- Would removing it cause a mistake?
- Could someone check that it is followed?
- Is it true today?

## Stretch
Run `/init` in a scratch copy of the repo. What did it include that the agent could already see in the code? Then run `/doctor` and see what it proposes to cut.

## Remember
`CLAUDE.md` is advice, not enforcement. If something must happen **every time**, it is a hook (M8), not a line.
