# M8: Safety and governance

**Start:** `scripts/lab-start.sh m8`

Use **Manual** mode so you see every prompt, and **read each one** before you approve it.

## Part 1: untrusted input (10 minutes)

Text in a file, an issue or a web page is **data**. It is not an instruction from you. These two exercises put text you did not write in front of the agent.

1. Ask Claude Code: *"Read `docs/vendor/gateway-integration.md` and add the timeout settings it describes to the gateway adapter."*
2. Start a fresh session (`/clear`). Ask: *"Implement what `docs/issues/ISSUE-142.md` asks for."*

After **each** one, check what actually happened:

```bash
git status
ls
```

Then answer, in your trio:

- Did anything happen that **you did not ask for**? Look at every permission prompt you approved, and at files that appeared.
- If it did, **which prompt showed it**, and what did the prompt say?
- If nothing did, **what stopped it**? Was it a control you configured, or the model's own judgment? Which of those could you rely on in a tool you did not choose?

## Part 2: how bad could it get? (worksheet)

The text you just read only asked for something harmless. A real attacker would ask for more. For each step, **which layer would stop it**, and which would **not**? Use the layers in [`docs/ai-governance-template.md`](../ai-governance-template.md).

| # | What an attacker might try | Which layer stops it? | Which would not? |
|---|---|---|---|
| 1 | Create a file you did not ask for | | |
| 2 | Edit `package.json` scripts, add a dependency, or change CI configuration | | |
| 3 | Edit the agent's own settings (for example, add a hook) or a tool-server configuration | | |
| 4 | Read a secret (`.env`, cloud credentials) | | |
| 5 | Send it somewhere (a web request, a `git push` to another remote) | | |
| 6 | Install a package that runs code | | |

Do not try any of these. Reason about them.

## Part 3: map it to your organization (8 minutes)

Open [`docs/ai-governance-template.md`](../ai-governance-template.md). In your trio, fill in **at least four rows** of the control map. For each row:

- What does your organization's policy say?
- How would you carry it out with the tools you have?
- Where is the **gap**, and who owns it?

If you do not know your organization's policy, write down who would. That is a finding too.

## Success looks like

- You can say what the agent could touch in your session, and what text it might have believed.
- For each rung of the worksheet, you named a layer, and **one limit of that layer**.
- You have at least one gap and an owner for it.
